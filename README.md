## Regras do Jogo
- Você deve clicar na cor certa para prosseguir para a próxima rodada
- Clicar na cor errada faz uma dedução de pontos
- O jogo termina na 10ª rodada
- Você tem 8 segundos por rodada
- A quantidade de quadrados disponíveis aumentam conforme as rodadas avançam

## Instruções para Jogar
- Ente no site e clique no botão "Iniciar Jogo" no meio da página
- O jogo foi iniciado, passe o mouse por cima da grade com uma série de quadrados coloridos
- As instruções que você precisará estarão na tela
- O jogo consiste em clicar na cor correta, a quantidade de quadrados aumentarão conforme as rodadas passam
